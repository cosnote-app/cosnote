# コスノート 公式サイト（GitHub Pages 用）

`https://cosnote-app.github.io/cosnote/` に置く静的サイト。仕様は `../landing-page-spec.md`。
このフォルダの中身をそのまま `cosnote-app/cosnote` repo のルートに置く（`.nojekyll` を含む）。

- `index.html` — LP
- `privacy/index.html` — プライバシーポリシー（ASC の Privacy Policy URL）
- `support/index.html` — サポート（ASC の Support URL）
- `assets/` — CSS / JS / アイコン（C-gold-1 の縮小）/ 実画面（raw-6.9-r3 を幅 720 の JPEG に縮小）

App Store の URL が取れたら、`index.html` の 2 か所の `cta soon` を Apple 公式バッジ＋リンクに差し替える（コメント参照）。
